# Pilot metrics

Track these metrics with clear definitions and privacy-conscious aggregation:

- **Lookup success rate:** successful provider responses / total provider requests.
- **Address validation completion:** completed user validation flows / started flows.
- **Correction rate:** addresses edited after a provider-backed suggestion / suggestions selected.
- **Provider latency:** p50, p95, and p99 response time.
- **Provider error rate:** timeouts, 5xx, throttles, and invalid responses by category.
- **Operational outcome:** failed-delivery or address-related support rate for pilot cohorts, where customers can share reliable measurements.
- **Adoption:** weekly active operators and lookups per tenant.

Do not present demo dashboard values as measured production results. Establish baseline, observation window, cohort definition, and privacy review before reporting pilot outcomes.
